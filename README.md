MindLink
**온디바이스 AI 기반 마음 건강 케이 및 대구 지역 자원 연결 시스템**

경북대 사회복지학부 바이브 코딩 대회를 위해 제작된 프로젝트로, 사용자의 자가 진단 데이터와 앱 사용 패턴을 분석하여 마음 건강 상태를 조기에 감지합니다. 
모든 데이터는 외부 서버로 전송되지 않고 기기 내에서만 처리되는 On-Device 방식을 지향합니다.

 ✨ 주요 기능
- 스플래시 화면: 감각적인 파티클 효과와 함께 서비스 아이덴티티 전달
- 자가 진단 (Check): 수면, 우울, 에너지 등 9가지 지표 분석
- AI 결과 분석: 분석된 점수를 바탕으로 현재 상태를 3단계로 분류
- 지역 자원 연결: 경북대 학생상담센터 및 대구 지역 전문 기관 정보 맞춤 제공

 🚀 실행 방법 (How to Run)
이 프로젝트는 별도의 서버 설치가 필요 없는 순수 웹(HTML/CSS/JS) 프로젝트입니다.

1. 이 저장소를 클론(Clone)하거나 ZIP 파일로 다운로드합니다.
   bash
  git clone [https://github.com/사용자이름/저장소이름.git](https://github.com/사용자이름/저장소이름.git)

3. 프로젝트 루트 폴더에 있는 index.html 파일을 브라우저(Chrome, Edge 등)로 엽니다.

4. 또는 VS Code에서 Live Server 확장 프로그램을 사용하여 실행하는 것을 권장합니다.

🔒 보안 및 개인정보
- 본 프로젝트는 사용자의 민감한 심리 데이터를 다루므로, 모든 로직은 브라우저(Client-side)에서 처리됩니다.
- 입력된 데이터는 어디로도 전송되지 않으며 페이지를 새로고침하면 초기화됩니다.
